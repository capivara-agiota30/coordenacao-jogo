# Instruções para Claude Code

Repositório de coordenação: https://github.com/capivara-agiota30/coordenacao-jogo
Branch compartilhada: main.

Antes de trabalhar no jogo, leia a versão atual de AGENTS.md neste repositório e siga suas regras de coordenação. Consulte também alteracoes-pendentes.md, estado-das-ias.md e alteracoes.md na versão atual pelo acesso autenticado ao GitHub.

O nome fixo desta IA será informado no prompt de configuração. Não invente nem reserve um nome antes disso. Confirme a experiência alvo e os sistemas sob sua responsabilidade.

Edite o jogo no Roblox Studio por MCP. O GitHub guarda apenas a coordenação; não configure sincronização de scripts nem copie código do jogo para este repositório.

Só comece a editar depois de obter a reserva em estado-das-ias.md com gravação condicionada à versão lida, como definido em AGENTS.md. Se os acessos necessários ou o controle de concorrência não estiverem disponíveis, informe o impedimento e não suponha que a reserva foi adquirida.

A presença deste arquivo no GitHub não instala instruções no Claude Code de outro computador. Na configuração inicial, coloque este CLAUDE.md na pasta de trabalho que será aberta no Claude Code ou forneça estas instruções explicitamente na conversa. Não é necessário clonar o repositório para consultar e atualizar os documentos pela API.
